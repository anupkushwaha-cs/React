## Getting Started

Clone the repository:

```bash
git clone https://github.com/anupkushwaha-cs/React.git
```

Navigate to the project directory:

```bash
cd React
```

Navigate to the required project folder and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
